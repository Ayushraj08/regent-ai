# HVAC Configuration Flow

## Services
- AC repair
- Heating/furnace repair
- Maintenance
- Installation/replacement
- Thermostat
- Other

## Urgency Classifications
- System down
- Partially working
- Routine
- Estimate

## Emergency Signals (Conservative Escalation)
If a customer reports any of the following, Regent must immediately escalate and flag the lead as HIGH urgency (and potentially trigger human transfer if configured):
- Smoke
- Burning smell
- Fire
- Gas smell
- Dangerous electrical issue
